# Studiul_Individual_2_Magazin_De_Haine
Studiu individual 2.2 – Generator de albume cu fotografii.

- Galerie: albume pe categorii, vizualizare mărită cu navigare (săgeți / Esc).
- Inventar: adăugare produse cu fotografie, modificare stoc, ștergere.
- Comenzi: comandă nouă (scade stocul), stări Nouă / Livrată / Anulată.
- Rapoarte: venit, bucăți vândute, valoare stoc, export CSV.

Rulare: deschide `index.html` în browser. Datele se salvează în localStorage.
